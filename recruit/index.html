社員の仕事の進め方

経験を記録し、成果を測り、学びを共有する。

西宮モコでは、連絡・知識・ファイル・数値を店舗や個人の中に閉じず、Notion を中心に会社全体で共有する仕組みで仕事をしています。ホールに立つ社員から経営層まで同じ道具で同じ情報を見ることが、私たちが大切にする「仲間からの信頼」の土台です。

この仕組みで実現している4つのこと

  • 紙の日報や、口頭だけの引き継ぎがありません。
  • 分からないことは、先輩の答えが残っているので検索できます。
  • 自分の提案や改善が、店舗の数字で確かめられます。
  • ホールで働きながら、クラウドツールと AI を使う力が身につきます。

相談は気軽に。依頼や引き継ぎは記録に残し、誰でも確認できるようにしています。
使い方は入社後の研修で一から教えます。入社時に専門知識は必要ありません。正社員には1人1台のノートパソコンを支給します。

知識と手順

Notion

マニュアル・タスク・議事録・日報を一か所に。質問と答えが積み上がるので、次に同じ場面に立つ人が同じことで困りません。

詳しく見る

会社の知識と仕事の中心です。議事録・業界ニュース・タスクを関連付けて管理し、必要な情報に検索でたどり着けるようにしています。

連絡

Slack

業務連絡はチャンネルに集めて、判断の経緯を残します。「誰に聞けばいいか」で手が止まりません。

詳しく見る

顧問の税理士・社労士も同じ場所でやり取りしているので、専門的な相談も記録に残ります。

ファイル・メール・会議

Google Workspace

Drive・Gmail・Meet を会社のアカウントで。どの店舗からでも同じ資料を開き、オンラインで会議ができます。

分析・制作・自動化

自社の AI エージェント

社員全員が使える AI エージェントを会社で用意しています。資料づくりや集計の手間が減り、その分を接客や改善に使えます。

詳しく見る

自社で構築した AI エージェントは Slack と Google Workspace につながり、社内の情報を参照しながら、デザイン生成（ChatGPT の画像生成・Seedance の動画生成・CapCut の動画編集）、月間の営業管理資料、業界ニュース・新台速報のまとめ資料の作成まで、ひとつの中で行えます。全店舗を統括する役職者は Claude Code で両店のデータを横断して確認しています。

事務の自動化

freee・Claude Code

シフト作成や会計・労務の事務は自動化し、人の手が要る作業を減らしています。その分を、お客様に向き合う時間にあてています。

詳しく見る

会計と人事労務は freee と API でつながっています。アルバイトのシフトは、Google フォームに入力した希望を Claude Code が集計して自動で作ります。

※ Slack、Notion、Google Workspace、ChatGPT、Claude、Seedance、CapCut、freee は各社の商標または登録商標です。
